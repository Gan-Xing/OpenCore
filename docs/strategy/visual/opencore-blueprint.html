OpenCore Strategy Blueprint

OpenCore（开元）是 AI Native 企业级全栈 Monorepo。此页是战略蓝图总览，只描述未来能力、模块边界和阶段路线，不代表已经实现业务模块。

Section 1: 系统总览

当前状态 S2

API/Admin 空主干。API 有 health 和 OpenAPI skeleton，Admin 有 Umi Max + Ant Design Pro 壳。

目标主线 TypeScript

NestJS、OpenAPI、SDK、module registry、Umi Max、OpenForge。

学习对象 RuoYi/Yudao

学习模块地图、权限粒度、代码生成器、精简版/完整版，不复制 Java/Vue。

本阶段禁区 No business code

不做登录、RBAC、数据库、CRM、ERP、MES、WMS、商城、支付、会员、多租户、RAG、Agent。

Section 6: 下一阶段建议

完成本战略包后，下一步不是写业务模块，而是进入 S3：contracts / shared / module-registry 基线。

先做

OpenAPI workflow、SDK 生成、权限码和菜单元数据、模块 registry schema。

再做

API foundation、Admin shell、RBAC、系统管理、监控工具。

后做

OpenForge MVP、消息中心、Approval Lite、可选模块设计。

明确不做

多租户、CRM、ERP、MES、WMS、商城、支付、会员、RAG、Agent。
